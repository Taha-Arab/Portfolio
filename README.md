# Taha Arab — Portfolio

Personal portfolio site for Taha Arab, mechanical engineering student at the University of Houston. Built with Next.js, featuring project write-ups and an AI-powered chat widget ("digital twin") that answers questions about his background, projects, and experience.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- TypeScript
